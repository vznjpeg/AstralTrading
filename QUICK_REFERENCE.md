## Quick Decision Matrix

```
Situation                  → Action
─────────────────────────────────────────────────────────
STRONG_BUY (90%+)          → Buy if price > support
BUY near support           → Good entry opportunity
SELL near resistance       → Take profits / reduce longs
STRONG_SELL (90%+)         → Reverse position to short
Multiple signals same date → Strongest setup (trade it)
HOLD alone                 → Wait for more signals
HIGH risk + LOW confidence → Skip this signal
```

## Three Methods at a Glance

### 🌙 Planetary Aspects (Moon/Mars angles)
- **Good at:** Short-term momentum shifts (3-5 days)
- **Confidence:** Moderate (60-80%)
- **Best use:** Combine with technical analysis
- **Red flag:** Single aspect = weak signal

### ↗️ Angular Displacement (Planet cycle tracking)
- **Good at:** Structural shift points (next 90/180/270/360 degrees)
- **Confidence:** High (80-90%)
- **Best use:** Position sizing and timeframe planning
- **Red flag:** Too far in future (low relevance)

### ◯ Eclipse Anchoring (Synchronized projections)
- **Good at:** Major reversals (1-2 weeks out)
- **Confidence:** Very High (85-95%)
- **Best use:** Macro timing, swing trades
- **Red flag:** Very old eclipse (less relevant)

## Risk Management Rules

### Position Sizing Formula
```
Risk per trade = Account Size × Risk %
Position Size = Risk ÷ (Exit Price - Entry Price)

Examples (1% account risk):
- $10,000 account = $100 risk per trade
- If stop is $5 away = 20 shares
- If stop is $10 away = 10 shares
```

### Stop Loss Placement
```
BUY signal near support
→ Stop = Support level - $0.50
→ Target = Next resistance

SELL signal near resistance  
→ Stop = Resistance level + $0.50
→ Target = Next support
```

### Confidence × Position Size
```
100% confidence (not possible) → 2% risk
90%+ confidence               → 1.5% risk
80-89% confidence             → 1% risk
70-79% confidence             → 0.5% risk
60-69% confidence             → Pass (hold only)
```

## Timeframe Guide

```
"Next 1-3 days"     → Market might start moving TODAY
                    → Don't wait more than 3 days
                    → Intraday/daily traders
                    
"Next 3-7 days"     → Swing traders (3-5 day holds)
                    → Watch for 4-5 candles
                    → Price often takes 2-3 days to react
                    
"Next 5-10 days"    → Intermediate traders
                    → Multiple candles to develop
                    → Less urgent, more time to enter
                    
"Next 10+ days"     → Position traders
                    → Long-term setup
                    → Good for weekly charts
```

## Daily Trading Routine

### Morning (Before Market Opens)
```
1. Check alerts on high-confidence signals coming today
2. Identify support/resistance near those signal dates
3. Plan your entries and exits
4. Set position size based on risk level
5. Set alerts 1 hour before signal time
```

### During Market Hours
```
1. Monitor price action around signal times
2. Wait for technical confirmation (reversal pattern)
3. When confirmed, execute trade with stop
4. Manage position (take profits at targets)
```

### Evening (After Close)
```
1. Journal the trade (setup, entry, exit, P&L)
2. Note which signal types worked best
3. Plan tomorrow based on upcoming signals
4. Update your swing high/low if exceeded
```

## Troubleshooting

### "I'm getting too many signals"
→ Only trade 90%+ confidence signals
→ Only trade when multiple methods agree
→ Wait for technical confirmation
→ Reduce position size for marginal signals

### "I got a signal but the move didn't happen"
→ Margin signals (70-79%) fail frequently
→ Check if move happened but in opposite direction
→ High risk signals can move suddenly (gap risk)
→ Did you miss the timeframe? (already happened)

### "What if the signal date passes with no move?"
→ Move can happen 1-2 candles late
→ Sometimes move happens but reverts
→ Market ignores some signals (no pattern trade confirmation)
→ This is why signal = WHEN, not IF

### "Should I update my swing point?"
→ If market breaks swing point, update it
→ Use new extreme as reference
→ Re-run analysis with new dates
→ Old swing points become irrelevant

## Common Patterns

### Pattern: Aspect Cluster
```
Multiple aspects within 3-5 days
→ Market likely to move in one of those days
→ Watch for 3+ aspects = highest probability
→ Usually sees reversal (5-20 points)
```

### Pattern: Phase Convergence
```
Displacement phase AND eclipse projection on same date
→ VERY HIGH probability (90%+)
→ Price often gaps or reverses hard
→ Perfect entry/exit points
```

### Pattern: Quiet Period
```
No signals for 2+ weeks
→ Market is in trend (following existing cycle)
→ Wait patiently for next signal cluster
→ Review technical patterns (trending vs choppy)
```
